# Evaluating subjective memory

The native memory mechanism preserves the existing reflection prompt and its test-only golden-format oracle. The Pi migration tests verify host integration and chronology using a deterministic model. They do not establish the quality of a particular live model's remembered prose.

For sustained play, evaluate these authored scenarios:

- A kind encounter with incidental objects: emotional gist should last longer than low-salience details.
- A companion who fears abandonment: distinguish subjective interpretation from independently witnessed events or the player's hidden motives.
- Episodes separated by years: express elapsed fictional time without inventing encounters in gaps.
- An origin scene played after adult scenes: exclude all future recollections and impressions.
- Rerolling a reply: only the selected alternative should influence the episode's eventual memory.
- Deleting an early episode: remove its direct memories and withhold later dependent interpretations until rebuilt.

Record the model/provider, character foundation, source message identities, fictional dates and memory explanations. Check who acted, who received an action, the difference between belief and observed fact, repetition, certainty and excessive retained detail. Do not treat schema-valid output as proof of semantic faithfulness.

Memory formation remains explicit and replaceable. A failed/cancelled operation preserves the published state, while explicit deletion immediately invalidates affected data without depending on a model.
