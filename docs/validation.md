# Validation and limits

The standalone checks run the locked Rust tests, build a release executable and exercise the host protocol from a separate process with deterministic source and model fixtures. They cover chronology, corrections, source changes, provenance, cancellation, stale updates, deletion, character isolation, database compatibility and atomic publication. See [development](development.md) for commands.

These tests verify the engine's behavior and the shape and attribution of memory context. [Subjective memory evaluation](subjective-evaluation.md) describes how to assess remembered prose in sustained play. The complete selected episode and eligible reflection context must fit the chosen model's context window.

The engine uses explicit Gregorian dates or zoned timestamps. The host owns branch selection, narrative continuity, transcript export and recovery, and the player experience.
