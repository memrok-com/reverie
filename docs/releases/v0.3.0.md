# Reverie v0.3.0

Hosts can now export and restore a character's existing subjective memory without
calling a model or regenerating recollections. The Rust API and JSON-lines
protocol add `exportMemory`, `previewImport` and `importMemory`. Protocol remains
version 1; older executables do not implement these operations.

Archives preserve episode dates and inclusion, recollections, impressions,
reviewed corrections and provenance, including stale memory and pending rebuilds.
Hosts retain canonical transcripts, branch choices and character foundations.
Import checks their source callbacks and the reviewed destination revision before
publishing atomically. Failed or cancelled work preserves previous memory, and
an exact retry remains safe after restart.

The version-1 archive uses compact dependency prefixes and validates the complete
dependency budget before expansion. Capacity errors return `ARCHIVE_TOO_LARGE`.
Transfer is limited to 64 MiB encoded JSON, 10,000 episodes, 4,000,000 decoded
dependency IDs and 128 MiB of UTF-8 text across those IDs. Complete histories can
reach the dependency limit in the low thousands of memorized episodes. Preview
includes downstream episodes affected by an earlier stale contribution.
See the [host transfer contract](../memory-transfer.md).

## Download and verification

The Windows x64 ZIP contains `reverie-engine.exe`, its source commit identifier,
LICENSE, NOTICE and third-party notices. Download the ZIP and `.zip.sha256`,
verify the digest and extract the complete folder. The executable needs no Node,
Rust, GCC or Pi installation. Linux users can build from this tag; no prebuilt
Linux or macOS executable is supplied.

The release checks include the full Rust and native/process suites, compact
dependency rejection, an exact 2,000-episode round trip, atomic rollback,
cancellation and restart/retry. Extracted-package verification repeats storage,
process and transfer tests with only Windows system tools on the engine's PATH.
Tests use isolated databases and deterministic host/model fixtures.

Doxvelt can bundle this independently released engine for combined workspace
archives. Legacy Pi ZIP migration remains a separate host responsibility;
upgrading Reverie does not migrate old Pi stories.
