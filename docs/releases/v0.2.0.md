# Reverie v0.2.0

Reverie is now a standalone Rust memory engine. Hosts own the interface,
canonical episode source, branch selection and model access. Reverie owns
subjective memory, reflection validation, chronology and local retrieval.

This release removes the Pi extension, its dependencies and npm-facing
integration. It is a breaking change for Pi users. The native JSON-lines
protocol remains version 1. Rust hosts can link the crate from source; this
release does not publish an npm package or crates.io package.

The Windows x64 ZIP includes `reverie-engine.exe`, a source commit identifier,
Apache-2.0 license and third-party notices. A separate `.sha256` file verifies
the ZIP. Extract the complete directory. The executable requires no Node,
Rust, GCC or Pi installation at runtime. A connected host supplies model work
through the protocol's reflection callbacks. See [connecting a host](../quickstart.md).

Linux x64 builds and the complete native suite run in CI. No prebuilt Linux
or macOS executable is included in this release. Windows packaging is verified
after extraction with storage and JSON-lines host tests.

## Existing Pi stories

Use the [final Pi integration revision](https://github.com/memrok-com/reverie/tree/518cb3e911e0fb5a056d7862179c2cae5b6d7c05)
to open and export existing stories. Its [story backup instructions](https://github.com/memrok-com/reverie/blob/518cb3e911e0fb5a056d7862179c2cae5b6d7c05/docs/story-backup.md)
remain available. Moving those archives into another host requires a host-side
importer. Upgrading this engine does not import Pi stories into Doxvelt.
